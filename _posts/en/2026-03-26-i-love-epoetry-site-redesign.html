I am pleased to announce that I have ported I ❤️ E-Poetry from WordPress to Jekyll using Claude Opus 4.6. I have ported the site to improve security and long term preservation for the site, which no longer depends on databases and is now implemented as a set of static HTML pages.

The new site has the following features:

  • Updated visual design
  • 100% bilingual site
  • A language toggle to switch between English and Spanish translations
  • Randomized access to entries to improve discoverability
  • Exploration tools through categories, authors, and search

Please reach out if you notice any errors, bugs, or other issues with the site.

Share and enjoy!
