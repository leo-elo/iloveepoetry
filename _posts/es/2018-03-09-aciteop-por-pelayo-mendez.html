Este poema generativo extrae palabras de un texto, ya sea el poema de Octavio Paz dedicado a Roman Jacobson después de su muerte, o el que usted proporcione. Varios algoritmos actúan sobre el texto: uno para seleccionar tres palabras del texto y buscar sinónimos que el lector puede seleccionar para reemplazar la palabra original, uno para determinar el color de la fuente, otro para realizar una búsqueda de imágenes de "Google"para una imagen de fondo que utiliza el color de fuente predominantemente, y un programa de texto de voz que lee las palabras en voz alta. El lector tiene cierto control sobre algunos de estos algoritmos y funciones de visualización, pero el más importante es la capacidad de guardar una imagen capturada en pantalla del poema generado, que ofrece una recompensa tangible para que los lectores se conviertan en creadores de contenido con este trabajo. También es una herramienta fascinante para el análisis textual porque sus cualidades "deconstructivas" resaltan nuevos grupos de palabras del texto original que permiten al lector reexperimentarlo con nuevos ojos. Presentado en ELO 2012 Media Art Show Traducido por Reina Santiago
