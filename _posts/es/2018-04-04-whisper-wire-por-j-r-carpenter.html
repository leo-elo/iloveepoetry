Hay un abundante ruido en estos tipos de comunicación: transmisiones cruzadas, estáticas, ecos y señales fantasmas, y para que se produzca una transmisión efectiva, tanto el emisor como el receptor deben ser oyentes competentes. Esta es una metáfora adecuada para este poema, en la que uno puede percibir que existe una relación señal ruido diferente de la que esperamos en los textos impresos. En otras palabras, algunas de las líneas pueden no tener sentido, pero otras son muy claras. ¿Qué líneas son las portadoras del mensaje de Carpenter? Podría afirmarse que todas las líneas están pensadas porque son el resultado de señales enviadas a través del software y hardware de su computadora para producir lo que se desplaza delante de usted en la pantalla. ¿Cuál es el mensaje original? El código fuente, que es una remezcla de "Taroko Gorge" de Nick Montfort utilizando variables modificadas (la primera de las remezclas para hacerlo) y conjuntos de datos meticulosamente seleccionados diseñados y probados para producir resultados que satisfagan la visión de Carpenter para el poema. Recomiendo explorar el código fuente (clic derecho -> ver fuente) para descubrir algunas de las materias primas que ha reunido para esta experiencia. Luego, explore algunos de sus otros poemas que usan este código siguiendo este enlace. J. R. Carpenter se destaca como el poeta que ha escrito la mayoría de las obras basadas en este código, haciéndolo responder a su propia poética particular. Traducido por Reina Santiago
